# 방송 진행

[← 차례로](index.md)

## 로그인 {#login}

`RequestHub.exe`를 실행하면 브라우저에 로그인 화면이 열립니다. 열리지 않으면 트레이 아이콘의 **관리자 화면 열기**를 누르거나 `http://localhost:8787/`을 직접 엽니다.

| 방법 | 하는 법 | 언제 |
|---|---|---|
| **카드키 파일** (권장) | `.piukey` 파일을 고르고 카드키 비밀번호를 넣습니다. | 늘 |
| **직접 입력** | API 키를 붙여 넣습니다. | 카드키를 아직 만들지 않았을 때. 화면 공유나 공용 PC에서는 쓰지 마세요. |

라이브 주소는 로그인 화면에서 같이 넣어도 되고, 나중에 연결 메뉴에서 넣어도 됩니다.
API 키는 프로그램 메모리에만 있고, **로그아웃**하거나 프로그램을 끄면 사라집니다.

## 메뉴 구성

| 메뉴 | 하는 일 |
|---|---|
| 대기열 | 지금 플레이, 대기 중인 신청곡, 확인 필요한 후원, 채팅 신청 로그, 숙제곡 |
| 완료 목록 | 끝난 곡. 복구하면 대기열 맨 뒤로 돌아갑니다. |
| 곡 검색·등록 | 곡을 찾아 대기열에 직접 넣습니다. |
| 랜덤 돌리기 | 조건 안에서 곡을 추첨합니다. |
| 후원 | 유튜브 슈퍼챗, 투네이션 설정 ([후원 신청](donations.md)) |
| 연결 | YouTube 라이브, OBS 주소, Google 로그인, 방송 전 점검 |
| 설정 | 신청 · 알림 · 화면 꾸미기 · 함께하는 사람 · 기타 ([설정](settings.md)) |

창이 좁으면 메뉴가 위쪽 가로 줄로 바뀝니다.

## 라이브 연결 {#connect}

**연결 → YouTube 라이브 연결**에 라이브 주소(`https://www.youtube.com/live/...`, `https://youtu.be/...` 등) 또는 11자리 영상 ID를 넣습니다. 연결되면 방송 제목, 상태, 수신 방식, 마지막 채팅 시각이 나옵니다.

**수신 방식** (다음 연결부터 적용)

| 방식 | 설명 |
|---|---|
| 자동 (권장) | 스트리밍으로 받고, 안 되면 폴링으로 바꿉니다. |
| 스트리밍만 | 할당량을 가장 적게 씁니다. |
| 폴링만 | 일정 간격으로 묻습니다. 할당량을 많이 씁니다. |

대기열 위쪽의 **채팅 수신 시간**은 마지막으로 채팅을 받은 시각입니다. 오래 멈춰 있으면 연결 메뉴의 상태를 확인하세요.

### 방송 전 점검

**연결 → 방송 전 점검**에서 시청자 이름과 채팅 내용을 넣고 **보내기**를 누르면, 실제 채팅이 들어온 것처럼 처리됩니다. YouTube로는 보내지 않습니다. 신청 처리, 오버레이, 효과음이 제대로 나오는지 방송 전에 확인하세요.

## 대기열과 지금 플레이

### 곡 시작과 완료

지금 플레이는 **저절로 넘어가지 않습니다**. 직접 시작해야 방송 화면의 "지금 플레이"에 나타납니다.

1. 대기 중인 신청곡에서 시작할 곡의 **▶(시작)**을 누릅니다.
2. 플레이가 끝나면 지금 플레이 칸의 버튼을 누릅니다.

| 버튼 | 하는 일 |
|---|---|
| 완료 | 완료 목록으로 옮깁니다. |
| 시작 취소 | 플레이를 취소하고 대기열 맨 앞으로 되돌립니다. |
| 뒤로 보내기 | 대기열 맨 뒤로 보냅니다. |

지금 플레이가 비어 있으면 "다음 순서"로 대기열 첫 곡을 알려 줍니다.

### 대기열 정리

- **순서 바꾸기**: 줄 왼쪽 손잡이를 끌거나, 손잡이에 초점을 두고 위아래 방향키를 누릅니다.
- **줄마다 있는 버튼**: 시작, 수정(채보 바꾸기), 완료, 삭제
- **여러 개 한 번에**: 체크한 뒤 **선택 삭제**. **전체 삭제**도 있습니다.
- **+ 곡 직접 등록**: 곡 검색·등록 화면으로 갑니다.
- **+ 후원 직접 등록**: 연동되지 않은 후원을 손으로 넣습니다. ([후원 신청](donations.md#manual))
- **새 방송 시작**: 대기열과 완료 목록을 모두 비웁니다. 숙제곡은 남습니다.

위쪽 숫자 칸은 대기 중, 완료, 최근 1시간 신청 실패 수, 마지막 채팅 수신 시각입니다.
**신청 받는 중 / 신청 마감** 표시로 지금 채팅 신청을 받는지 알 수 있습니다. 신청을 마감해도 후원곡은 받습니다.

### 채팅 신청 로그

들어온 신청과 그 결과(성공, 실패와 이유)가 실시간으로 쌓입니다. 시청자가 "왜 안 들어갔냐"고 물을 때 여기를 보세요.

## 채팅 명령

시청자가 라이브 채팅에 적는 명령입니다. 명령어 이름은 [설정 → 신청](settings.md#request)에서 바꾸거나 여러 개 둘 수 있습니다.

| 명령 | 예 | 설명 |
|---|---|---|
| 신청 | `/신청 고민중독 S20` | 곡 제목과 채보(스텝 타입 + 레벨) |
| | `/신청 고민중독 S20, 배니쉬 D24` | 쉼표로 여러 곡 |
| | `!신청 배니쉬 더블24` | `싱글/더블`, `S/D` 모두 됩니다. |
| | `/신청 ㄱㅁㅈㄷ s20` | 초성으로도 찾습니다. |
| | `/신청 곡제목 숏 S15` | 숏컷, 리믹스, 풀송을 구분할 때 |
| 신청권 사용 | `/후원신청 고민중독 S20` | 후원이나 룰렛으로 받은 신청권이 있을 때 |
| 레벨 조회 | `/레벨 고민중독` | 그 곡의 채보 목록을 알려 줍니다. (알림 설정이 필요합니다) |
| 본인 취소 | `/취소` | 내 마지막 신청을 취소합니다. |
| | `/취소 고민중독` · `/취소 고민중독 S20` | 특정 곡을 취소합니다. |

- 본인 취소는 **대기 중인 일반 신청**만 됩니다. 이미 시작했거나 후원으로 들어온 곡은 취소되지 않습니다. 설정에서 끌 수 있습니다.
- 곡을 못 찾거나, 1인 신청 수를 넘었거나, 대기 시간 안이거나, 중복이면 실패하고 이유가 알림과 로그에 남습니다.

## 곡 검색·직접 등록

제목(또는 초성), 스텝 타입, 레벨, 곡 종류로 찾습니다. 제목을 비우면 레벨이나 곡 종류만으로 찾습니다. 결과에서 **채보**를 누르면 바로 대기열에 들어갑니다.

곡 목록은 공개 곡 데이터에서 받아 옵니다. 새 곡이 반영되지 않으면 [설정 → 기타](settings.md#etc)의 **곡 목록 갱신**을 누르세요.

## 랜덤 돌리기

스텝 타입과 레벨 범위를 정하고 **랜덤 돌리기**를 누르면 곡을 추첨합니다.

- **애니메이션 건너뛰기**: 결과만 바로 보여 줍니다.
- **결과를 대기열에 자동 등록**: 끄면 결과를 보고 **대기열에 추가**를 눌러 넣습니다.
- 방송 화면에도 추첨 애니메이션이 함께 나옵니다. ([화면 꾸미기](overlay.md)에서 끌 수 있습니다)

## 숙제곡

방송인이 직접 정해 두는 곡 목록입니다. [설정 → 신청](settings.md#request)에서 **숙제곡 쓰기**를 켜면 대기열 화면 아래에 숙제곡 칸이 생깁니다.

- **+ 숙제곡 추가**로 등록하고, **전체 비우기**로 지웁니다.
- 새 방송을 시작해도 남습니다.
- 방송 화면의 **숙제곡** 블록에 나옵니다. 숙제 기한은 화면 꾸미기에서 적습니다.

## 함께하는 사람 (여럿이 플레이)

[설정 → 함께하는 사람](settings.md#people)에 방송인 이름과 추가 인원을 적으면, 신청곡·후원곡·숙제곡·지금 플레이마다 **플레이할 사람 버튼**이 생깁니다.

- 버튼을 누를 때마다 다음 사람으로 바뀝니다. (예: 방송인 → 친구A → 친구B → 누구나)
- 방송 화면에도 표시되고, **플레이어별** 블록으로 사람마다 나눠 보여 줄 수 있습니다.
