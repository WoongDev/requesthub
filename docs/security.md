# 보안과 자주 묻는 질문

[← 차례로](index.md)

## 무엇이 어디에 남나요

| 정보 | 보관 방식 |
|---|---|
| **YouTube API 키** | 프로그램 메모리에만 있습니다. 파일, 로그, 브라우저에 남지 않고 로그아웃하거나 끄면 사라집니다. |
| **카드키** (`.piukey`) | PBKDF2-HMAC-SHA256(60만 회) + AES-256-GCM. 비밀번호 없이는 열 수 없고, 파일이 조금이라도 바뀌면 열리지 않습니다. |
| **Google 로그인 정보** | Windows DPAPI로 암호화해 최대 24시간만 보관합니다. 지나면 Google에 폐기를 요청하고 지웁니다. 다른 API 키로 로그인하면 이어 쓰지 않습니다. |
| **OAuth 클라이언트** | "이 PC에 암호화해서 저장"을 켜면 DPAPI로 저장, 끄면 프로그램을 끌 때까지만 유지합니다. |
| **투네이션 위젯 주소** | 메모리에만 있습니다. 저장을 고르면 DPAPI로 암호화하고, 같은 API 키로 로그인했을 때만 다시 씁니다. |
| **대기열** (`queue.json`) | 시청자 이름과 채널 ID가 들어 있습니다. |

데이터 폴더: `%LOCALAPPDATA%\RequestHub` (트레이 아이콘 → 데이터 폴더 열기)

## 서버는 이 PC에서만 열립니다

Request Hub의 서버는 이 PC(127.0.0.1, ::1)에서만 접속할 수 있고, 다른 웹사이트가 브라우저를 통해 보낸 요청은 거부합니다. 같은 와이파이의 휴대폰이나 다른 PC에서는 접속되지 않습니다. 오버레이 데이터(곡 제목, 신청자 이름)는 이 PC 안에서는 로그인 없이 볼 수 있습니다.

## 절대 공개하면 안 되는 것

- YouTube API 키
- `client_secret_….json` (OAuth 클라이언트 보안 비밀번호)
- 카드키 파일과 그 비밀번호 (둘을 함께 두지 마세요)
- 투네이션 알림창 위젯 주소
- 데이터 폴더(`%LOCALAPPDATA%\RequestHub`)의 파일

## 자주 묻는 질문

**Q. 실행하면 Windows가 "PC 보호" 경고를 띄웁니다.**
서명되지 않은 프로그램이라서입니다. 릴리스에 적힌 SHA-256 값과 내려받은 파일의 값이 같은지 확인한 뒤 **추가 정보 → 실행**을 누르세요.

**Q. 포트 8787을 쓸 수 없다고 나옵니다.**
예전 Unity 신청곡 프로그램이나 Request Hub가 이미 켜져 있는지 확인하세요. 트레이에 아이콘이 남아 있을 수 있습니다.

**Q. 카드키 비밀번호를 잊었습니다.**
되찾을 수 없습니다. 카드키 생성기로 새로 만드세요. API 키가 걱정되면 Google Cloud에서 키를 다시 만들고 예전 키를 지우세요.

**Q. API 키 사용량이 빨리 닳습니다.**
연결 메뉴의 수신 방식을 **자동**이나 **스트리밍만**으로 두고, 채팅 답글(1회 약 50 유닛)을 줄이세요. 사용량은 연결 메뉴에서 볼 수 있습니다.

**Q. 투네이션 후원이 안 들어옵니다.**
후원 → 투네이션의 연결 상태를 보고 **다시 연결**을 눌러 보세요. 비공식 연동이라 투네이션이 방식을 바꾸면 끊길 수 있습니다. 그동안은 대기열의 **후원 직접 등록**을 쓰세요.

**Q. 새 곡이 검색되지 않습니다.**
설정 → 기타 → **곡 목록 갱신**을 누르세요.

**Q. 다른 PC로 옮기고 싶습니다.**
설정 → 기타에서 설정 파일을, 화면 꾸미기에서 프리셋을 각각 내보내 새 PC에서 가져오세요. 카드키 파일도 옮기면 됩니다. 키는 설정 파일에 들어가지 않습니다.
