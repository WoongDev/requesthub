# 설정

[← 차례로](index.md)

설정은 왼쪽 메뉴의 **설정** 아래 다섯 항목으로 나뉩니다. 화면 꾸미기는 [따로 설명](overlay.md)합니다.

## 신청 {#request}

### 명령어

쉼표로 여러 개를 적을 수 있습니다. (예: `/신청, !신청`)

| 항목 | 기본 |
|---|---|
| 신청 | `/신청`, `!신청` |
| 레벨 조회 | `/레벨`, `!레벨` |
| 신청권 사용 | `/후원신청`, `!후원신청` |
| 본인 취소 | `/취소`, `!취소` |

### 신청 제한과 기능

| 항목 | 설명 |
|---|---|
| 1인당 대기열 최대 신청 수 | 한 사람이 대기열에 동시에 올릴 수 있는 곡 수 |
| 같은 사람의 다음 신청까지 대기 시간 | 없음, 30초, 1분, 3분, 5분, 10분 |
| 같은 곡·같은 채보 중복 신청 막기 | 이미 대기열에 있는 채보는 받지 않습니다. |
| 본인 신청 취소 허용 | `/취소` 명령을 쓸 수 있게 합니다. |
| 숙제곡 쓰기 | 켜면 대기열 화면에 숙제곡 칸이 생깁니다. |

후원곡에는 1인 신청 수와 대기 시간 제한이 적용되지 않습니다.

## 알림 {#notify}

위에서부터 차례로 고릅니다. 아래쪽 **지금 설정으로는**에 고른 결과가 문장으로 정리되어 나옵니다.

1. **무엇을 알릴지**: 신청 결과(성공·실패, 후원 신청 포함), 레벨 조회, 본인 취소
2. **어디에 알릴지**: 방송 화면 / 채팅 답글 / 둘 다 / 알리지 않음
3. **방송 화면에는 어떻게 띄울지** (방송 화면을 골랐을 때)

| 방식 | OBS | 설명 |
|---|---|---|
| 신청곡 목록 안에 포함 | 소스 하나 | 신청곡 목록 오버레이의 위나 아래에 붙습니다. |
| 따로 띄우기 | 소스 두 개 | `http://127.0.0.1:8787/overlay/reply`를 OBS에 따로 넣고 위치와 크기를 직접 정합니다. 목록에는 알림이 나오지 않습니다. |

- **채팅 답글**은 Google 로그인이 필요하고 답글 1회에 약 50 유닛을 씁니다. ([OAuth 준비](setup.md#oauth))
- **신청 성공·실패 효과음**: 알림이 뜨는 오버레이에서 소리가 납니다. OBS에서 그 브라우저 소스의 오디오가 켜져 있어야 합니다.
- **시험 알림 띄우기**로 방송 화면에 미리 띄워 볼 수 있고, **모양 바꾸기**를 누르면 화면 꾸미기의 알림 탭으로 갑니다.

## 함께하는 사람 {#people}

| 항목 | 설명 |
|---|---|
| 방송인 이름 | 내 이름 |
| 추가 인원 | 같이 플레이하는 사람. 쉼표로 구분합니다. |

추가 인원을 적으면 신청곡, 후원곡, 숙제곡마다 누가 플레이할지 정하는 버튼이 생깁니다. 누를 때마다 다음 사람으로 바뀌고, 방송 화면에도 표시됩니다.

## 기타 {#etc}

| 항목 | 설명 |
|---|---|
| 설정 파일 내보내기 / 가져오기 | 룰렛 구간을 포함한 설정을 다른 PC로 옮깁니다. API 키 같은 비밀 정보는 들어가지 않습니다. 화면 꾸미기 프리셋은 화면 꾸미기에서 따로 내보냅니다. |
| 곡 목록 갱신 | 공개 곡 데이터에서 최신 곡 목록을 다시 받습니다. |
