# 후원 신청

[← 차례로](index.md)

후원 메뉴는 **유튜브 슈퍼챗**과 **투네이션**으로 나뉘고, 저마다 사용 여부와 **신청할 수 있는 곡 조건**(스텝 타입, 레벨, 곡 종류, 곡 수)을 따로 정합니다. 치지직과 SOOP은 자리만 있고 아직 쓸 수 없습니다.

## 기본 원리

- **금액은 보지 않고 후원 글에 적힌 곡만 봅니다.** 글에 곡이 여러 개면 모두 찾습니다.
- 후원곡은 1인 신청 수와 대기 시간 제한을 받지 않고, 신청을 마감해도 받습니다.
- 조건이나 곡 수에 맞지 않거나 곡을 알 수 없으면 대기열 위쪽 **확인 필요한 후원 · 신청권**에 남습니다.
- **후원자가 적은 곡 수 따르기**: 켜면 글에 설정보다 많은 곡 수가 적혀 있을 때 그 수로 확인 필요에 올립니다. 끄면 설정한 곡 수를 씁니다.
- **오버레이에 후원 금액 표시**(공통): 방송 화면의 후원곡에 금액을 같이 보여 줍니다.

## 확인 필요 처리 {#pending}

확인 필요 항목마다 후원자, 금액, 글, 남은 곡 수, 조건이 나옵니다. 곡 수는 −/+로 고칠 수 있고, 처리 방법은 셋 중 하나를 고릅니다.

| 처리 | 하는 일 |
|---|---|
| **내가 곡 정하기** | 곡 검색 화면에서 방송인이 직접 골라 넣습니다. |
| **후원자가 채팅에서 고르기** | 조건을 **직접 설정**하거나 **룰렛 기준에 따라 설정**한 뒤 **대기 확정**을 누릅니다. 후원자가 채팅에 `/후원신청 곡제목 S21`처럼 적으면 들어갑니다. |
| **곡 신청 받지 않기** | 신청 없이 정리합니다. |

- 신청권이 여러 개면 조건에 맞는 것끼리 나눠 씁니다.
- 채널이 확인되지 않은 후원자(투네이션 등)의 채팅 선택은 **방송인이 수락해야** 들어갑니다.
- 조건 창에서 **이 문구를 룰렛 기준으로도 저장**을 체크하면 다음부터 같은 문구를 자동으로 처리합니다.

## 유튜브 슈퍼챗

따로 연결할 것이 없습니다. 라이브에 연결하면 채팅과 함께 들어옵니다.

- 외화는 표시를 위해 공개 환율(Rates By [Exchange Rate API](https://www.exchangerate-api.com))로 원화로 바꿉니다. **갱신**으로 새로 받을 수 있습니다.
- 슈퍼스티커는 메시지가 없어 확인 필요로 남습니다.

## 투네이션 (비공식 연동)

1. 투네이션 대시보드에서 **알림창(alertbox) 위젯 주소**를 복사합니다. (`https://toon.at/widget/alertbox/...`)
2. 후원 → 투네이션의 **알림창 위젯 주소**에 통째로 붙여 넣고 **등록하고 연결**을 누릅니다.
3. **이 PC에 암호화해서 저장**을 켜 두면 같은 API 키로 로그인할 때 자동으로 연결합니다. 공용 PC라면 끄세요. 카드키에 넣어 두어도 됩니다.

연결 상태와 마지막 후원 시각이 표시되고, **다시 연결 / 끊기 / 주소 지우기**를 할 수 있습니다.

> 알림창 주소를 아는 사람은 누구나 후원 알림을 볼 수 있습니다. 방송 화면, 캡처, GitHub에 드러나지 않게 하세요. 투네이션이 방식을 바꾸면 연결되지 않을 수 있고, 그때는 아래 **후원 직접 등록**을 쓰세요.

### 글 후원

후원 글에 적힌 곡을 신청으로 받습니다. 신청할 수 있는 곡 조건을 정합니다.

### 룰렛 후원

패널 안에서 따로 켜고 끕니다. **금액이 아니라 후원 메시지에 들어온 문구**로 구간을 나눕니다.

- **+ 구간 추가**: 구간마다 인식할 문구, 일치 방식(메시지에 들어 있으면 / 결과와 똑같을 때만), 처리(신청권 주기 / 신청 아님: 꽝, 벌칙), 조건과 곡 수, 대기열 위치를 정합니다. **문구를 읽어 조건 채우기**로 문구에서 조건을 자동으로 채울 수 있습니다.
- **여러 개 붙여넣기**: 한 줄에 구간 하나씩 붙여 넣습니다. 조건을 읽을 수 없는 줄은 "신청 아님"으로 들어갑니다.
- 투네이션 룰렛은 `룰렛 이름 - 결과` 모양으로 들어오므로 결과만 적어도 되고 이름까지 적어도 됩니다. 문구가 여러 구간에 맞으면 더 긴 문구를 따릅니다.
- 결과에 구간이 여러 개 들어 있으면 신청권도 여러 개 생깁니다.
- **적어 두지 않은 결과도 읽어 보기**: `싱글/더블 21↓ 2곡`처럼 조건이 보이는 결과는 신청권으로 만들고 확인을 기다립니다.
- **어느 구간에 걸리는지 시험**: 문구를 넣어 보면 어느 구간에 걸리는지 알려 줍니다. 대기열에는 넣지 않습니다.
- 곡 종류는 곡 목록의 `channel` 값으로 구분합니다. (5 숏컷, 6 리믹스, 7 풀송, 나머지 아케이드)

## 후원 직접 등록 {#manual}

대기열의 **+ 후원 직접 등록**으로 연동되지 않은 후원을 손으로 넣습니다.

| 방식 | 설명 |
|---|---|
| 후원 글로 등록 | 후원 글을 넣으면 자동 연동과 똑같이 곡을 찾습니다. |
| 신청권 주기 | 곡 없이 신청권만 줍니다. 후원자가 채팅에서 고릅니다. |

- 후원자는 **이번 방송 채팅에 글을 남긴 사람** 중에서 고릅니다. YouTube는 글을 쓰지 않은 시청자를 알려 주지 않습니다.
- 어느 후원인지(투네이션 / 유튜브 슈퍼챗)를 고르면 그 후원의 조건과 룰렛 기준이 똑같이 적용됩니다. 금액은 표시용입니다.
- **룰렛 기준에서 고르기**로 룰렛 결과를 바로 고를 수도 있습니다.
