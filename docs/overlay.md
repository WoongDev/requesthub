# 방송 화면 꾸미기와 OBS

[← 차례로](index.md)

## OBS에 넣기 {#obs}

1. OBS의 소스 목록에서 **+ → 브라우저**를 고릅니다.
2. URL에 `http://127.0.0.1:8787/overlay`를 넣습니다. (트레이 아이콘의 **오버레이 주소 복사**나 연결 메뉴의 **URL 복사**로 복사할 수 있습니다)
3. 너비와 높이는 화면 꾸미기에서 정한 크기와 똑같이 맞춥니다. 같을 때 가장 또렷합니다.
4. 배경은 투명하니 따로 손댈 것이 없습니다.
5. 효과음을 쓰면 **OBS로 오디오 제어** 여부와 오디오 믹서에서 그 소스가 음소거되지 않았는지 확인합니다.

| 주소 | 쓰임 |
|---|---|
| `http://127.0.0.1:8787/overlay` | 신청곡 현황 (방송 중인 프리셋) |
| `http://127.0.0.1:8787/overlay/reply` | 알림을 **따로 띄우기**로 골랐을 때의 알림 |
| `…/overlay?block=req` | 블록 하나만 (아래 블록 이름 참고) |
| `…/overlay?preset=프리셋ID` | 방송 중인 프리셋과 상관없이 특정 프리셋 고정 |

화면 꾸미기에서 **방송에 적용**하면 OBS 주소는 그대로 두고 화면만 바뀝니다. Request Hub를 다시 켜도 OBS 쪽은 손댈 필요가 없습니다.

## 화면 꾸미기

**설정 → 화면 꾸미기**에는 **신청곡 현황**과 **알림 오버레이** 두 탭이 있습니다. 오른쪽 미리보기에서 바로 결과를 보며 고칩니다. (곡 많을 때, 실제 자료로, 투명 부분 보기를 켜서 확인할 수 있습니다)

### 프리셋

- 기본 프리셋은 목록 12종, 알림 3종입니다. 고르면 아래에서 바꿀 수 있습니다.
- 기본 프리셋을 고쳐도 원본은 남고 **내 프리셋**으로 저장됩니다.
- **복제 / 저장 / 지우기 / 방송에 적용**
- **내보내기 / 가져오기**: 프리셋을 파일로 주고받습니다. 올린 그림도 함께 들어갑니다.

### 블록 (신청곡 현황)

화면에 넣을 블록을 켜고 순서를 정합니다. 블록 하나만 따로 OBS 소스로 넣을 수도 있습니다.

| 블록 | `?block=` 값 | 내용 |
|---|---|---|
| 지금 플레이 | `now` | 대기열에서 ▶를 누른 곡 |
| 신청곡 | `req` | 일반 신청 대기열 |
| 후원곡 | `don` | 후원곡을 신청곡과 나눠 표시 |
| 숙제곡 | `hw` | 대기열 화면에서 등록한 숙제곡 |
| 플레이어별 | `players` | 함께하는 사람마다 나눠 표시 |
| 후원 순위 | `rank` | 이번 방송 합계 |
| 진행 수 | `count` | 누적·완료 수 |
| 시계·방송 종료 | `clock` | 현재 시각과 방송 종료 시각 |
| 공지 | `notice` | 직접 적은 공지 문구 |

블록 아래에서 신청곡 제목, 공지 문구, 방송 종료 시각, 숙제 기한을 적습니다.

### 모양과 표시 항목

- **형태**: 목록 / 한 곡 표시, **스킨**, 글자 정렬, 너비·높이(px), 안쪽 여백
- **보여 줄 항목**: 제목줄, 진행 수, 순번, 채보, 신청자, 랜덤 표시, 영문 곡명, 페이지 번호, 후원 금액, 플레이할 사람, 완료한 곡도 표시
- **한 화면에 보여 줄 곡 수**, 빈 칸도 번호로 표시, 곡이 더 많을 때(넘기기 등)와 넘기는 간격
- **지금 플레이가 없을 때** 보여 줄 내용, **랜덤 돌리기 추첨 화면 보이기**

### 알림 오버레이

- 신청 성공·실패 알림의 **위치, 모양, 나타나는 방법, 보여 주는 시간, 동시에 보이는 개수**
- **실패도 표시**: 끄면 성공만 보여 줍니다.
- **방송 화면에 시험 알림 띄우기**

### 글꼴과 색

- **글꼴**: 이 PC에 설치된 글꼴 중에서 고릅니다. 기본은 Pretendard입니다. OBS를 다른 PC에서 돌린다면 그 PC에도 같은 글꼴이 있어야 합니다.
- 글자 크기, 강조색, 글자색, 칸 배경색과 불투명도, 칸 모서리, 칸 테두리, 칸 그림자, 글자 그림자

### 테두리

- **테두리 모양**, 주 색, 강조색, 두께, 모서리 크기, 빛 번짐, 안 채우기/채우기 색, **테두리를 따라 흐르는 빛**
- **내 테두리 그림 올리기**: 투명 PNG·WebP. 모서리 보존 크기만큼 모서리를 지키며 늘어납니다.

### 전체 배경

- 배경색, **배경 그림 올리기**(PNG·JPG·WebP·GIF, 8MB까지), 맞춤, 어둡게, 흐림
- SVG는 안에 코드를 넣을 수 있어 받지 않습니다.
- 어느 프리셋에서도 쓰지 않는 그림은 프로그램을 켤 때 지웁니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| OBS 화면이 비어 있음 | Request Hub가 켜져 있는지, 주소가 `127.0.0.1:8787`인지, 브라우저 소스의 **새로 고침**을 눌러 봅니다. |
| 글자가 흐림 | OBS 소스 크기와 화면 꾸미기의 너비·높이가 같은지 |
| 지금 플레이가 안 나옴 | 대기열에서 ▶를 눌렀는지 (저절로 넘어가지 않습니다) |
| 알림이 안 나옴 | 설정 → 알림에서 "방송 화면"을 골랐는지, "따로 띄우기"라면 `/overlay/reply` 소스를 넣었는지 |
| 효과음이 안 남 | 알림이 뜨는 소스의 오디오가 OBS에서 켜져 있는지 |
