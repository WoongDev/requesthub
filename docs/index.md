# Request Hub 사용 설명서

Request Hub는 유튜브 라이브 채팅으로 들어오는 펌프 신청곡을 곡 목록과 대조해 대기열로 만들고, 그 대기열을 관리자 화면과 OBS 방송 화면에 실시간으로 보여 주는 프로그램입니다. 내 PC 안에서만 동작하는 작은 서버라서 설치나 회원가입이 없습니다.

## 차례

1. [준비하기](setup.md): API 키 발급, 카드키 만들기, OAuth 클라이언트(선택)
2. [방송 진행](broadcast.md): 로그인, 라이브 연결, 대기열과 지금 플레이, 채팅 명령, 숙제곡, 함께하는 사람
3. [후원 신청](donations.md): 유튜브 슈퍼챗, 투네이션 글 후원과 룰렛, 확인 필요 처리
4. [설정](settings.md): 신청, 알림, 함께하는 사람, 기타
5. [방송 화면 꾸미기와 OBS](overlay.md): 프리셋, 블록, OBS 브라우저 소스
6. [외부 공개와 시청자 신청 페이지](public.md): 임시 주소, 고정 주소(내 도메인), 시청자 로그인
7. [보안과 자주 묻는 질문](security.md)

## 한눈에 보기

```
[YouTube 라이브 채팅] ──► Request Hub (내 PC, 포트 8787) ──► 관리자 화면 (브라우저)
[투네이션 알림창]     ──┘                                 └─► OBS 오버레이 (브라우저 소스)
```

| 파일 | 하는 일 |
|---|---|
| `RequestHub.exe` | 본 프로그램. 실행하면 작업 표시줄 트레이에 아이콘이 생기고 관리자 화면(`http://localhost:8787/`)이 열립니다. |
| `CardKeyMaker.exe` | 카드키 생성기. API 키를 내가 정한 비밀번호로 암호화해 `.piukey` 파일로 저장합니다. 인터넷에 연결하지 않습니다. |

**필요한 환경**: Windows 10/11 64비트, 브라우저, OBS Studio(방송 화면용).
포트 8787을 쓰므로 예전 Unity 신청곡 프로그램과 동시에 켤 수 없습니다.

## 처음 한 번만 하는 일

1. [API 키를 발급](setup.md#api-key)합니다.
2. [카드키를 만듭니다](setup.md#cardkey). (권장)
3. 채팅 답글이나 시청자 신청 페이지를 쓸 생각이면 [OAuth 클라이언트](setup.md#oauth)를 만듭니다.
4. OBS에 [브라우저 소스를 추가](overlay.md#obs)합니다.

## 방송할 때마다 하는 일

1. `RequestHub.exe`를 켜고 카드키와 비밀번호로 [로그인](broadcast.md#login)합니다.
2. 연결 메뉴에 [라이브 주소](broadcast.md#connect)를 넣습니다.
3. 필요하면 대기열의 **새 방송 시작**으로 지난 방송의 대기열과 완료 목록을 비웁니다.
4. 곡을 시작할 때 대기열에서 **▶**를 누르고, 끝나면 **완료**를 누릅니다.
5. 방송을 마치면 트레이 아이콘에서 **종료**를 누릅니다. API 키는 메모리에서 지워집니다.

## 트레이 아이콘 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 관리자 화면 열기 | 브라우저로 관리자 화면을 엽니다. |
| 오버레이 주소 복사 | OBS에 넣을 주소를 복사합니다. |
| 데이터 폴더 열기 | `%LOCALAPPDATA%\RequestHub`를 엽니다. 대기열, 설정, 프리셋, 로그가 있습니다. |
| 종료 | 프로그램을 끕니다. |
