# 준비하기

[← 차례로](index.md)

처음 한 번만 하면 됩니다. 1번과 2번은 꼭 필요하고, 3번은 채팅에 답글을 달고 싶을 때만 합니다.

## 1. YouTube API 키 발급 {#api-key}

Request Hub는 내 API 키로 라이브 채팅을 읽습니다. 키는 무료이고, 하루 사용량(기본 10,000 유닛) 안에서 씁니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에 방송용 Google 계정으로 로그인합니다.
2. 위쪽 프로젝트 선택 메뉴에서 **새 프로젝트**를 만듭니다. 이름은 아무거나 괜찮습니다. (예: `requesthub`)
3. **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3`를 찾아 **사용**을 누릅니다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**를 누릅니다.
5. 만들어진 키의 **수정**에서 **API 제한사항 → 키 제한**을 고르고 `YouTube Data API v3` 하나만 체크해 저장합니다.

> API 키는 비밀번호와 같습니다. 화면 공유, 방송 화면, 메신저, GitHub 어디에도 그대로 올리지 마세요.

API 키 사용량은 관리자 화면의 **연결** 메뉴에서 볼 수 있습니다.

## 2. 카드키 만들기 {#cardkey}

카드키는 API 키를 내가 정한 비밀번호로 잠근 파일(`.piukey`)입니다. 로그인할 때마다 키를 붙여 넣지 않아도 되고, 키가 화면이나 클립보드에 드러나지 않습니다.

1. `CardKeyMaker.exe`를 실행합니다. 인터넷에 연결하지 않고, 입력한 값은 PC 밖으로 나가지 않습니다.
2. 칸을 채웁니다.

   | 칸 | 내용 |
   |---|---|
   | YouTube API 키 | 1번에서 만든 키 |
   | 카드키 이름 (선택) | 파일 이름과 구분용. 암호화되지 않으니 비밀을 적지 마세요. |
   | 비밀번호 / 비밀번호 확인 | 10자 이상. 길고 다른 곳에서 쓰지 않는 문장을 권장합니다. |
   | 채팅 답글용 OAuth 클라이언트도 함께 넣기 (선택) | 체크하면 `client_secret.json`을 불러오거나 클라이언트 ID와 보안 비밀번호를 직접 넣을 수 있습니다. ([3번](#oauth)) |
   | 투네이션 알림창 위젯 주소 (선택) | 넣어 두면 로그인할 때 투네이션이 함께 연결됩니다. |

3. **만들기**를 누르고 저장할 곳을 고릅니다. 저장이 끝나면 화면의 입력값은 모두 지워집니다.

**꼭 알아 둘 것**

- 비밀번호는 어디에도 저장되지 않습니다. 잊으면 되찾을 수 없으니 카드키를 새로 만드세요.
- 카드키 파일과 비밀번호를 같은 곳(같은 폴더, 같은 메모)에 두지 마세요.
- 파일이 1바이트라도 바뀌면 열리지 않습니다. 백업은 복사본으로 하세요.
- 암호화 방식: PBKDF2-HMAC-SHA256(60만 회)로 비밀번호에서 키를 만들고 AES-256-GCM으로 암호화합니다. 프로그램 안에 숨겨 둔 키가 없어서 비밀번호 없이는 열 수 없습니다. 그만큼 안전성은 비밀번호의 길이에 달려 있습니다.

## 3. 채팅 답글용 OAuth 클라이언트 (선택) {#oauth}

신청 결과나 레벨 조회 결과를 **채팅 답글**로 보내려면 Google 로그인이 필요하고, 그러려면 내 OAuth 클라이언트가 있어야 합니다. 방송 화면 알림만 쓴다면 이 단계는 건너뛰세요.

1. Google Cloud 콘솔의 같은 프로젝트에서 **API 및 서비스 → OAuth 동의 화면**(Google 인증 플랫폼)을 설정합니다.
   - 사용자 유형은 **외부**, 앱 이름과 이메일은 아무거나 괜찮습니다.
   - 게시 상태가 **테스트**라면 **테스트 사용자**에 방송 계정을 추가합니다.
2. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**를 누릅니다.
   - 애플리케이션 유형: **웹 애플리케이션** (데스크톱 앱이 아닙니다)
   - 승인된 리디렉션 URI: `http://localhost:8787/auth/callback` (한 글자도 다르면 안 됩니다)
3. 만들어진 클라이언트의 **JSON 다운로드**로 `client_secret_….json` 파일을 받습니다.
4. 이 파일을 다음 중 한 곳에 넣습니다.
   - 카드키 생성기의 **채팅 답글용 OAuth 클라이언트도 함께 넣기** (권장)
   - 관리자 화면 **연결 → Google 로그인 → OAuth 클라이언트**에서 **client_secret.json 불러오기**
5. 관리자 화면 **연결**에서 **Google 계정으로 로그인**을 누르고 방송 계정을 고릅니다.

**알아 둘 것**

- 요청하는 권한은 `youtube.force-ssl` 하나이고, 채팅에 답글을 쓰는 데만 씁니다.
- 답글 한 번에 약 50 유닛을 씁니다. 신청이 많은 방송이라면 하루 10,000 유닛을 넘지 않도록 알림을 방송 화면 위주로 쓰세요.
- 로그인 정보는 암호화해 최대 24시간만 보관하고, 지나면 Google에 폐기를 요청한 뒤 지웁니다. 다음 날에는 다시 로그인하면 됩니다.
- `client_secret_….json` 파일은 카드키나 관리자 화면에 넣은 뒤 지우거나 안전한 곳에 옮겨 두세요.

## 체험 모드

YouTube에 연결하지 않고 화면과 기능만 둘러보려면 명령 프롬프트에서 `RequestHub.exe --demo`로 실행합니다. 아무 값으로나 로그인할 수 있고, 데이터 폴더도 따로(`RequestHub-demo`) 씁니다.
